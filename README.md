# golangMicroservices

Learning repository for Go, working toward building microservices.

## Structure

| Path | Topic |
|------|-------|
| `core_language/variables` | Variable declaration and basic types |
| `core_language/constant` | Constants |
| `core_language/enums` | Enum-style constants with `iota` |
| `core_language/project` | `LogLevel` enum with a `String()` method |
| `code_flow/if-else` | Conditionals with `if`, `else if` and `else` |
| `code_flow/for-loop` | Loops: counted, condition-only, infinite, `continue` and `range` |

## Run an example

Each folder is its own `main` package:

```bash
go run ./core_language/variables
```
